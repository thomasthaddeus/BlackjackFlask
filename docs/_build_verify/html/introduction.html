Introduction

Blackjack Flask is a browser-based Blackjack game built on Flask with a JavaScript-driven front end. The current version is centered around a casino table presentation, multi-seat play from a shared bankroll, and a Poetry-based development workflow.

Current highlights

  • Up to 7 playable seats from one bankroll

  • Dealer hand centered above a semicircle table layout

  • Split, double down, surrender, and round-resolution logic

  • Session-backed game state across requests

  • A multi-deck shoe that persists across hands

  • Basic-strategy recommendations displayed in the UI

  • Front-end and CLI devtools for deterministic scenario testing

  • Loguru-based runtime logging with rotating log files

State and persistence

Gameplay state is currently stored in the Flask session. That means the active table, bankroll, and hand progression persist across requests for the same browser session, but they are not yet implemented as durable user accounts or saved game records.

Developer workflow

The repository is maintained as a Poetry-first project. Dependency installation, testing, documentation builds, and CI are all expected to run through Poetry commands.
