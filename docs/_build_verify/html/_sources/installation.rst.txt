Installation
============

Follow these steps to set up and run the current Blackjack Flask application.

Clone the repository
--------------------

::

   git clone https://github.com/thomasthaddeus/BlackjackFlask.git
   cd BlackjackFlask

Install dependencies with Poetry
--------------------------------

::

   poetry install --with dev,docs

Run the application
-------------------

::

   poetry run python run.py

The default local URL is ``http://127.0.0.1:5001``.

Runtime options
---------------

The application can be configured with environment variables.

Useful values include:

- ``FLASK_CONFIG=DevelopmentConfig|TestingConfig|ProductionConfig``
- ``PORT=5001``
- ``BLACKJACK_LOG_LEVEL=DEBUG``
- ``BLACKJACK_DEVTOOLS=1``
- ``BLACKJACK_LOG_SINK=logs/custom.log``
- ``BLACKJACK_LOG_RETENTION=14``
- ``BLACKJACK_LOG_TO_CONSOLE=1``

To start the app with verbose logging:

::

   poetry run python run.py --log-level DEBUG

Logging behavior
----------------

By default, the application writes timestamped logs under ``logs/`` with names
like ``blackjack-YYYYMMDDHHMMSS.log``. Logs rotate daily or when the file size
reaches about 10 MB, and older logs are retained according to the configured
retention count.
