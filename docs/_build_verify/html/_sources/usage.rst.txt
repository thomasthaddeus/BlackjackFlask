Usage
=====

Once the application is running, open ``http://127.0.0.1:5001`` in your
browser.

Starting a table
----------------

On first entry, the UI opens a seat-selection modal. Choose how many seats you
want to play from the shared bankroll, then start the table.

Table layout
------------

The current interface is organized into three main areas:

- Dealer hand centered at the top of the table
- Seat pods arranged around the felt semicircle
- Sidebar panels for betting, strategy guidance, and table status

The active seat is highlighted directly on the table. The larger player-hand
panel shows the current active seat's hands, including split hands.

Playing a hand
--------------

- Use the bet slider to choose a wager
- Select ``Place Bet`` to deal the next hand
- Use ``Hit`` to draw a card
- Use ``Stand`` to end the current hand
- Use ``Double Down`` to double the current hand and receive exactly one more card
- Use ``Split`` when the current hand is eligible
- Use ``Surrender`` when allowed

The dealer hole card remains hidden until the round resolves.

Strategy guide
--------------

The sidebar shows strategy advice based on the active player hand and the
dealer up card. The recommendation updates as the active hand changes during
play.

Developer tools
---------------

When devtools are enabled, the front end exposes an overlay for injecting exact
hands, deck order, bankroll values, and round state. This makes it possible to
verify gameplay behavior directly in the browser without relying on random
deals.

There is also a CLI harness for deterministic route-level testing:

::

   poetry run python -m app.tools.devtools --scenario split_eights --action hit --action stand --log-level DEBUG

Common development commands
---------------------------

::

   poetry install --with dev,docs
   poetry run pytest -q
   poetry run sphinx-build -b html docs/source docs/_build
