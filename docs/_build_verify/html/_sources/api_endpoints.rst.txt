API Endpoints
=============

The current Flask blueprint is mounted under ``/blackjack``.

HTML routes
-----------

- ``GET /blackjack/``: Main game page
- ``GET /blackjack/game_status``: Render the current table state as HTML

Gameplay JSON routes
--------------------

- ``POST /blackjack/start``: Start or reset a table, optionally with a selected seat count
- ``POST /blackjack/bet``: Place the opening bet and deal a new round
- ``POST /blackjack/action/hit``: Hit the active hand
- ``POST /blackjack/action/stand``: Stand the active hand
- ``POST /blackjack/action/double_down``: Double down the active hand
- ``POST /blackjack/action/split``: Split the active hand when eligible
- ``POST /blackjack/action/surrender``: Surrender the active hand when eligible

Compatibility routes
--------------------

- ``POST /blackjack/double_down``: Compatibility route that delegates to the action handler
- ``POST /blackjack/split``: Compatibility route that delegates to the action handler

Developer routes
----------------

When devtools are enabled:

- ``GET /blackjack/devtools/options``: List built-in deterministic scenarios
- ``POST /blackjack/devtools/seed``: Seed an exact table state into the session

Response shape
--------------

Gameplay routes return JSON payloads used by the front end. Those payloads
include current dealer information, bankroll, current bet, seat metadata,
active-hand information, strategy guidance, round status, and control-state
flags such as whether split, double down, or surrender are currently allowed.
